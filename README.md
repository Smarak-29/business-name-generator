# ⚡ NameCraft — AI-Powered Business Name Generator

A fast, intuitive tool that generates catchy, brandable, and industry-tailored business names along with instant domain and social handle availability checks.

---

## ✨ Features

- **Keyword & Vibe Matching:** Generates brand names based on industry, niche keywords, and target tone (e.g., modern, classic, playful, tech-forward).
- **Instant Domain Check:** Quick lookup for `.com`, `.io`, `.co`, and other common TLDs.
- **Social Handle Availability:** Live availability checks across Twitter/X, Instagram, and GitHub.
- **Favorites & Export:** Save shortlisted names and export them to JSON or CSV.
- **Fast & Responsive:** Lightweight, mobile-friendly interface with instant search results.

---

## 🛠️ Tech Stack

- **Frontend:** React / Next.js / Tailwind CSS
- **Backend:** Node.js / Express
- **AI / Generation Engine:** OpenAI API / Custom naming algorithm
- **DNS / Domain Lookup:** WHOIS API / DNS Over HTTPS (DoH)
